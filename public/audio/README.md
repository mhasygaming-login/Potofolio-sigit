# Folder Audio Portofolio per Mode

- `public/audio/gdg-bogor.mp3` — Soundtrack berulang (*loop*) untuk **GDG Bogor Mode** (*The Polished Canvas*).
- `public/audio/network.mp3` — Soundtrack berulang (*loop*) untuk **Network Mode** (*Protokol Terkunci*).
- Konfigurasi terpusat berada di `src/audio/modeMusicConfig.ts` dan dikelola oleh `src/utils/modeMusicPlayer.ts` (mulai dari `00:00` saat pergantian mode manual, tanpa kontrol UI audio tambahan).
